### 1.5 Test sweep script (written, parse-verified, NOT executed)

`backend/scripts/run-test-sweep.ps1` — one command that creates the scratch database,
runs the migrations, boots the API against scratch and executes the safe suites, saving
`docs/test-results.csv`. Behaviour:

- **Hard guards:** refuses any `PgHost` other than localhost/127.0.0.1; refuses to start if
  port 3001 is occupied (so tests can never reach an already-running live backend); never
  reads or writes `backend/.env` (dotenv does not override pre-set process env, so the
  exported scratch URLs win).
- Creates `umodzi_test` if absent, runs the twelve migrations as superuser
  (`MIGRATIONS_DATABASE_URL`), then prints the four post-migration checks
  (postgis_version, public table count, accepted-offer guard index, RLS policy count).
- Boots the API on port 3001 with scratch env and a generated `JWT_SECRET`, polls `/health`.
- Best-effort seeds a scratch administrator (public register as customer, then a SQL
  promote to `administrator`); public registration of administrators stays rejected.
- Runs 28 backend + 10 frontend safe suites (schema audits `task351-rls-audit` and
  `task352-final-integrity-check` last), captures exit codes and passed/failed counts.
- Writes the CSV **including eight EXCLUDED rows with the reason for each**, stops the
  server process tree, and exits non-zero if any suite failed.
- **Excluded (never run by the sweep):** `task352-retire-service-key.ts` (rewrites
  `backend/.env`), `task352-switch-connection.ts` (rewrites `.env`),
  `task352-create-runtime-role.ts` (writes `.env`), `task352-set-search-path.ts` and
  `task352-grant-extensions-usage.ts` (live Supabase role maintenance),
  `task352-tls-probe.ts` (probes the live pooler, writes a cert),
  `task352-searchpath-debug.ts` (live debug probe), `task33-gemini-smoke.mjs`
  (needs an external Gemini key).
- PowerShell parse check: **PASS**. **Not executed** — it requires the local postgres
  password, which is deliberately not stored in the repository or in this file.

Run it with:

